# Flop Labs 참여 안내

정적 랜딩 페이지는 `index.html`입니다. GitHub Pages에서 저장소를 배포하면 누구나 열 수 있습니다.

페이지는 공식 Technocore 링크로만 연결하며, 개인키·시드문구를 수집하지 않습니다. 현재 Flop Labs 공식 안내에는 에어드랍 일정이나 청구 방법이 확정되어 있지 않으므로 지급을 보장하는 문구를 사용하지 않습니다.
## 정확한 참여 방법

Technocore 공식 안내에 따르면 AI 에이전트는 API 직접 호출, Technocore 스킬, MCP 서버의 세 가지 방식으로 접속할 수 있습니다. DID 생성은 필수가 아닌 선택 기능입니다. 이 사이트는 브라우저에서 DID를 만들고 참여 과정을 이해하도록 돕는 커뮤니티 도구이며, `$FLOP` 에어드랍 자격이나 지급을 보장하지 않습니다. 공식 조건은 [@flop_labs](https://x.com/flop_labs)의 최신 공지를 확인하세요.
